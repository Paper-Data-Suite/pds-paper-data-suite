## Results and deliberate limits

E3B2 shows only aggregate physical-page and Core-review status counts. A
`handler_returned` does not prove student evidence capture or published grades.
If an exception escapes, the post-retention menu explicitly reports an
**uncertain result**, warns that producer effects *may* already exist, and
never retries. Neither a failed/partial result nor Back/Quit reverses prior
Core custody. The menu does not navigate back into first consent and does not
repeat D within one local invocation. Previously reported after-retention V
behavior remains backwards compatible.

This is an **entry-point source integration**; it does not establish that the
teacher's installed interpreter is an admitted Python 3.11 environment. In
particular, the developer `.venv` could be Python 3.13 and E3B2 must refuse
producer dispatch in that case. It does not qualify physical scanners,
Quillan end-to-end evidence capture, grading, multi-module partial admission,
Linux, or the full installed Teacher Home pilot. #19E4/F/G are still required.
