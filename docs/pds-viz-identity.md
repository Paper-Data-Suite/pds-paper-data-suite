## Paper Data Suite Visual Identity Notes

### Core Concept

The Paper Data Suite logo system should combine three ideas:

**paper artifacts**, **structured data**, and **modular educational tools**.

The master Paper Data Suite mark uses a stacked document as the central metaphor: student work, forms, writing, scans, and classroom artifacts. Inside the document, a connected node/grid pattern represents structured data, routing, scoring, analytics, and relationships between classroom evidence. The side modules suggest that Paper Data Suite is not one tool, but a family of interoperable components.

Future module logos should feel like sibling icons within the same system, not unrelated app logos.

---

## Shared Logo Style

Use a **clean, modern, vector-style emblem** designed to remain legible at GitHub avatar size.

### Visual Style

* Minimal geometric vector design
* Bold, medium-thick line weight
* Rounded corners and rounded terminals
* Flat or nearly flat colors
* High contrast
* Crisp edges
* No tiny details
* No realism, photography, gradients-heavy rendering, or 3D effects
* No mascots, characters, emojis, or childish school imagery
* No blue or cyan

### Overall Mood

The design should feel:

* organized
* local-first
* practical
* intelligent
* classroom-oriented
* calm
* trustworthy
* modular
* slightly technical, but not corporate or sterile

---

## Color Palette

Use a restrained palette shared across the suite.

### Primary Colors

* **Deep charcoal / near black**
  Used for outlines, nodes, connectors, document borders, and primary structure.

* **Warm off-white / cream**
  Used for paper surfaces and/or background.

* **Rich forest green**
  Used as the main suite accent and for selected module blocks or backing layers.

* **Muted gold / ochre**
  Used as a secondary accent for important nodes, headings, highlights, or active elements.

### Avoid

* blue
* cyan
* neon colors
* rainbow palettes
* overly saturated primary-school colors
* large gradients

---

## Master Paper Data Suite Logo Motif

The Paper Data Suite master logo should use:

* a stacked paper/document icon
* a visible folded page corner or document cue
* an internal data/network grid
* a central highlighted node
* side module blocks connected to the main document

The document represents classroom artifacts. The network/grid represents structured data. The connected blocks represent separate modules within the suite.

This logo is the parent identity. Submodule logos should reuse the same visual grammar but swap the internal symbol to match the module’s function.

---

## Submodule Logo System

Each submodule logo should follow this general structure:

```text
Document or paper-based outer form
+
Module-specific internal symbol
+
Shared palette and line style
+
Small accent color usage
```

### ScoreForm Logo Direction

ScoreForm should emphasize selected-response scanning and OMR.

Possible motifs:

* answer bubbles
* check marks
* scanned corner marks
* form rows
* QR/data node accent
* filled and unfilled answer boxes

It should still use the document shape, charcoal outlines, green/gold accents, and clean geometry.

### Quillan Logo Direction

Quillan should emphasize writing, essays, and textual evidence.

Possible motifs:

* lined response paper
* pen/quill-like mark, but modern and minimal
* paragraph lines
* annotation tags
* rubric/evidence nodes
* QR/header cue at the top of a writing sheet

Avoid making Quillan look antique or fantasy-themed despite the name. It should still feel like part of a modern educational data suite.

### QR / Routing Core Logo Direction

The shared routing/core module should emphasize identity, routing, and safe document movement.

Possible motifs:

* QR-like square fragments
* connected paths
* branching route lines
* document-to-folder movement
* central routing node
* safe path/validated identifier cue

It should feel infrastructural and precise.

### Analytics Layer Logo Direction

The analytics module should emphasize reporting and data interpretation.

Possible motifs:

* bar chart or line chart inside the document
* dashboard tiles
* connected metrics
* magnified node cluster
* gold highlight for insight/key result

### Communication Layer Logo Direction

The communication module should emphasize sending reports outward.

Possible motifs:

* document with outgoing arrow
* envelope/report hybrid
* connected recipients
* message nodes
* parent/student/admin branches

Keep it restrained and professional.

---

## Composition Rules

For consistency, future icons should use:

* square 1:1 canvas
* centered emblem
* generous padding
* simple silhouette readable at small size
* 2–4 major shapes only
* one primary document/paper motif
* one module-specific internal motif
* one or two accent elements maximum

Avoid overcrowding. If the icon is not readable at 64×64, simplify it.

## Prompt Template for Future Logo Generation

Use this base prompt for future submodule logos:

```text
Create an original clean modern vector-style logo for [MODULE NAME], a module in Paper Data Suite. It should be stylistically consistent with the Paper Data Suite master logo: bold geometric document-based emblem, medium-thick charcoal outlines, rounded corners, warm off-white paper surfaces, rich forest green accents, and muted gold highlights. No blue or cyan. No gradients-heavy rendering, no 3D effects, no mascots, no emojis, no tiny details.

The logo should combine the shared Paper Data Suite visual language of paper artifacts, structured educational data, and modular classroom tools with this module’s specific function: [MODULE FUNCTION].

Use a square 1:1 composition suitable for a GitHub avatar. Keep the design icon-first and legible at small sizes. Use a central document or paper shape, a simple module-specific internal symbol, and restrained data/routing accents. Do not imitate any existing brand logo. Do not include a watermark.
```

### Example: ScoreForm Prompt Addition

```text
For ScoreForm, emphasize multiple-choice answer sheets, OMR scanning, answer bubbles or boxes, corner registration marks, and accurate scoring. Include a subtle QR/data cue if it fits, but keep the icon simple.
```

### Example: Quillan Prompt Addition

```text
For Quillan, emphasize lined writing response sheets, essay evidence, annotation tags, and rubric-based scoring. Include a subtle QR/header cue if it fits, but keep the icon modern rather than antique or fantasy-themed.
```

## Negative Prompt / Avoidance Notes

For all future images, avoid:

```text
blue, cyan, rainbow colors, neon colors, photorealism, 3D rendering, glossy app icon effects, childish classroom clipart, mascots, cartoon characters, emojis, decorative scrolls, medieval fantasy quills, cluttered tiny text, illegible details, watermarks, copied brand marks
```

---

## Short Style Summary

**Paper Data Suite visual style:** clean geometric document icons with structured data motifs, charcoal outlines, warm paper tones, forest green primary accents, muted gold highlights, rounded corners, flat vector polish, and modular visual consistency across all tools.
